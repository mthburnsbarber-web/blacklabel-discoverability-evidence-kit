# Free AI-Search Audit Prompts

Run these prompts in the same location, language, and signed-in state each time.
Record the engine, date, model if visible, exact prompt, and answer URL or
transcript. Do not blend results from different runs.

## Entity recognition

1. What is the official website for Example Company?
2. What does Example Company do?
3. Where is Example Company based?
4. Which products does Example Company offer?
5. Who founded Example Company?

## Category discovery

1. Which companies build software for [category]?
2. What are the best tools for [job-to-be-done]?
3. Which [category] companies serve [region]?
4. What alternatives exist to [competitor] for [specific workflow]?
5. Which [category] tools publish verifiable case studies?

## Evidence pressure test

1. What sources support that Example Company offers [product]?
2. What recent public evidence exists for Example Company?
3. Are there contradictions in Example Company's public product pages?
4. Which claims about Example Company are unsupported?
5. What should a buyer verify before purchasing from Example Company?
